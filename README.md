# Сфера доверия — республиканский мониторинг школьного климата

Анонимный опрос для учеников (область/город/школа/класс+буква) + отдельный кабинет
психолога на каждую школу (видит только свои анкеты) + публичная страница агрегированной
статистики по всем регионам Казахстана. Интерфейс на русском и казахском.

## Стек

- Клиент: React + Vite, React Router, recharts (график ролей), собственный i18n (`src/i18n`)
- Сервер: Node.js + Express + Prisma + SQLite
- Авторизация психолога: JWT, один аккаунт = одна школа (region/city/school фиксированы в БД)

## Запуск

### 1. Сервер

```
cd server
npm install
npx prisma migrate dev
npm run seed
npm run dev
```

Поднимется на http://localhost:4000. Демо-логин психолога после сидирования: `psycholog` / `bulling2026`
(школа «Демо-школа» — специально вне списка регионов, чтобы не попадать в публичную статистику).

### 2. Клиент

```
cd client
npm install
npm run dev
```

Поднимется на http://localhost:5173, запросы к `/api/*` проксируются на сервер (см. `client/vite.config.js`).

## Создать аккаунт для школы

Публичной регистрации нет — каждая школа получает доступ вручную:

```
cd server
node scripts/create-admin.js <логин> <пароль> "<область из списка>" "<город/район>" "<школа>"
```

Список допустимых областей — в `server/src/utils/locations.js` (17 областей + 3 города РК).

## Структура

- `server/prisma/schema.prisma` — модели Question (+textKz), Admin (+region/city/school), Submission (+region/gradeLetter), Answer
- `server/src/utils/locations.js` — канонический список регионов РК и букв класса
- `server/src/utils/scales.js` — какие вопросы относятся к какой из 4 шкал методики, расчёт среднего балла и уровня
- `server/src/routes/stats.js` — статистика кабинета психолога, жёстко ограниченная его школой (не берёт city/school из query)
- `server/src/routes/public.js` — публичная агрегированная статистика по регионам (`/api/public/summary`), без авторизации
- `client/src/i18n/translations.js` — словарь RU/KZ для публичных страниц
- `client/src/pages` — главная (каскадная форма), о проекте, карта климата, опрос, спасибо, вход психолога, дашборд, редактирование вопросов

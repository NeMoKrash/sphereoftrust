# Сенім аясы / Сфера доверия — республиканский мониторинг школьного климата

Живая версия: **https://sphereoftrust.nullstudio.pw/**

Анонимная веб-платформа для диагностики буллинга и психологического климата в школах
Казахстана: анонимный опрос для учеников (область → район/город → школа → класс),
отдельный кабинет психолога на каждую школу (видит только анкеты своей школы),
супер-админка для управления доступами и просмотра статистики по всей стране,
публичная страница агрегированной статистики по регионам. Интерфейс двуязычный —
русский и казахский.

## Стек

- **Клиент**: React 19 + Vite, React Router, Recharts (графики), собственный i18n (`client/src/i18n`)
- **Сервер**: Node.js + Express + Prisma ORM + SQLite
- **Авторизация**: JWT (12 часов) + bcrypt-хэширование паролей, две роли — школьный психолог и супер-администратор
- **Инфраструктура**: VPS (Ubuntu) + Nginx + PM2, Cloudflare (домен/SSL)

## Роли и разграничение доступа

| Роль | Доступ |
|---|---|
| Ученик | Проходит опрос анонимно, без регистрации и личных данных |
| Школьный психолог | Видит статистику и анкеты **только своей школы** — ограничение проверяется на сервере по данным его аккаунта, а не по параметрам запроса |
| Супер-администратор | Статистика по всей республике с фильтрами (область/район/школа/класс), создание и удаление аккаунтов психологов |

## Запуск локально

### 1. Сервер

```
cd server
npm install
npx prisma migrate dev
npm run seed
npm run dev
```

Поднимется на http://localhost:4000.

### 2. Клиент

```
cd client
npm install
npm run dev
```

Поднимется на http://localhost:5173, запросы к `/api/*` проксируются на сервер (см. `client/vite.config.js`).

## Создание аккаунтов

Публичной регистрации нет — доступ выдаётся вручную через серверные скрипты.

Школьный психолог:
```
cd server
node scripts/create-admin.js <логин> <пароль> "<область из списка>" "<район/город>" "<номер школы>"
```

Супер-администратор (владелец платформы, доступ ко всей статистике РК):
```
cd server
node scripts/create-superadmin.js <логин> <пароль>
```

Канонический список из 20 регионов РК (17 областей + города Астана, Алматы, Шымкент
как отдельные регионы верхнего уровня) — в `server/src/utils/locations.js`.

```

  src/utils/locations.js     — канонический список регионов РК и букв класса

  src/middleware/auth.js     — requireAdmin / requireSuperAdmin (проверка JWT)
  src/routes/
    submissions.js           — приём анкет от учеников

  scripts/

    create-superadmin.js     — выдать доступ супер-администратору

client/src/
  i18n/translations.js       — словарь RU/KZ
  data/regions.js            — регионы + районы/города для каскадной формы
  pages/
    HomePage, AboutPage, AuthorPage, ClimateMapPage   — публичные страницы
    StartPage, SurveyPage, ThankYouPage               — прохождение опроса
    AdminLoginPage, AdminLayout, AdminDashboardPage,
    AdminQuestionsPage                                — кабинет школьного психолога
    SuperAdminLayout, SuperAdminStatsPage,
    SuperAdminAdminsPage                              — супер-админка
```

## Методология

Опросник построен на теоретической модели прямой и косвенной виктимизации/агрессии
(в частности, подход Д. Олвеуса). Ответы группируются в 4 шкалы — прямая виктимизация,
косвенная виктимизация (отвержение), прямой активный буллинг, косвенный активный
буллинг — каждая оценивается средним баллом от 0 до 4 (`server/src/utils/scales.js`).
